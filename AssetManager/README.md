# Asset Manager (Web Edition)

This repository contains the web-based Asset Management system.

## Project Structure

- **AssetManager_Dev/**: Development environment (Testing & Staging).
- **AssetManager_Prod/**: Production environment (Stable Release).
- **recovery_v1.7/**: Backup of legacy components and libraries.
- **POLICY.md**: Development workflow and environment policies.

## Quick Start

Navigate to the appropriate environment directory (e.g., `AssetManager_Dev` or `AssetManager_Prod`) and follow the instructions in the `web-app` directory.

### Key Directories

- `web-app/`: Contains the Frontend and Backend code.
- `data/`: Stores the SQLite database and configuration files.
- `input/`: Directory for uploaded files (images, logos).
- `export/`: Directory for generated reports.
