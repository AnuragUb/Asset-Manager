# ops/deployment/

Launch helpers for local/test runs.

| Script | Purpose |
|--------|---------|
| `run-test.bat` | Starts backend with `PORT=9090` and test data dirs |
| `run-prod.bat` | Reminder note for production folder/port 8080 |

`run-test.bat` changes directory into `web-app/asset-manager-backend` using a path relative to this folder.
