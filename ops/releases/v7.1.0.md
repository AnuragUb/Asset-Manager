## Scope

**Purpose**

Deliver Sprint 1 platform foundations and record them as the current **cut** release for AssetEngine.

**Business reason**

Move from a working internal tool toward a structured EAM platform: recoverable deletes, auditable inventory movements, consistent lifecycle language, and operable auth reset.

**Engineering reason**

Land shared Event System, Recovery Center, Inventory Movement (CONSUME), Lifecycle model, soft-delete, and gated deploy/docs workflow on a single tip commit suitable for promotion.
